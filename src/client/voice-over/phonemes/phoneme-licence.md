# Who recorded the phonemes

Every `.wav` file in this folder was recorded by Wizzaroo's owner and prepared with `pnpm prepare:phonemes`.

| What                            | Source                           | Licence                                                                                                                               |
| ------------------------------- | -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| The 44 phoneme recordings       | Recorded by Wizzaroo's owner     | © Wizzaroo's owner, all rights reserved. They may be used in Wizzaroo only                                                            |
| `ffmpeg`, which reads each take | [ffmpeg.org](https://ffmpeg.org) | LGPL-2.1 or later, or GPL as built by Homebrew. It runs on a developer's machine to make the files and is never shipped with Wizzaroo |

Replacing a recording with one from anywhere else means changing this file in the same commit, with the new recording's source and licence.
