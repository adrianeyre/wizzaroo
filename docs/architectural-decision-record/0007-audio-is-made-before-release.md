# All audio is made before release; nothing is generated while a Child plays

> **Personal use only.** Wizzaroo is intended for your own personal use only. It is not intended for use with or by a school, teacher, parent or student. Only use it for yourself.

Voice-over is generated before release with a good UK English text-to-speech voice and shipped as static audio files. Phonemes are recorded by the owner, or taken from a properly licensed set, in the order and terminology of the school's phonics programme. Browser speech synthesis, and AI of any kind, is never used during child play: it sounds different on every device, often isn't UK English, and handles pure phonemes (/m/, not "em") badly. Generating audio before release doesn't break the "no live AI in the game" rule, because nothing is generated while a Child plays.

**Amended by [ADR 0060](./0060-read-it-to-me-reads-questions-and-messages-in-a-chosen-voice.md):** when a Child presses **Read it to me**, the device's own speech voice reads the question or message on screen, in a voice chosen on the Settings page. Everything Wizzaroo says by itself, and every phoneme, is still recorded before release.
